# GTFS Enhancer

A Python tool that utilizes the OSRM MapMatching API and OSM data to clean up GTFS geographic data.

## Features

- **Route Shape Cleanup**: Snaps GTFS shapes to the road network using OSRM, removing veering stretches and "stop tail" artifacts.
- *(Planned)* **Stop Location Optimization**: Uses OSM data to validate and snap bus stop locations.

## Setup

1. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```

2. Run tests:
   ```bash
   pytest
   ```
